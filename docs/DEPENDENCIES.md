# Зависимости интеграционного контракта

Дата проверки: 2026-08-22.

## `github.com/a2aproject/a2a-go/v2` `v2.5.0`

- Назначение: использовать настоящие типы протокола A2A `TaskState` и обнаруживать
  несовместимость на этапе компиляции.
- Источник: официальный репозиторий проекта A2A.
- Лицензия: Apache License 2.0.
- Версия: точный релиз `v2.5.0`, совпадающий с зависимостью зафиксированного
  commit kagent.
- Альтернатива с локальной копией типов отклонена: она уже привела к неверным
  значениям протокола в нижнем регистре и не обнаруживает изменение API.

Сгенерированный API kagent и A2A protobuf не копируются в этот репозиторий. При
обновлении source lock версия зависимости заново проверяется вместе с
совместимостью, лицензией и полным графом зависимостей.

## Результат проверки

- Подлинность: модуль загружен из официального `a2aproject/a2a-go`, версия и
  контрольные суммы зафиксированы в `go.mod` и `go.sum`.
- Сопровождение: официальный репозиторий не архивирован; стабильный релиз
  `v2.5.0` опубликован 2026-08-18 и совпадает с версией в kagent.
- Фактически компилируемый граф содержит два внешних модуля:
  `a2a-go/v2@v2.5.0` и его косвенную зависимость `google/uuid@v1.6.0`.
  Полный модульный граф `go list -m all` содержит 17 внешних модулей и должен
  пересматриваться при каждом изменении pin.
- Лицензии: `a2a-go/v2` — Apache-2.0, `google/uuid` — BSD-3-Clause. Лицензия
  самого интеграционного репозитория пока не утверждена, поэтому этот результат
  не является разрешением на публикацию релизного артефакта.
- `govulncheck v1.7.0` на Go 1.26.5 не обнаружил уязвимых символов, достижимых
  из текущего кода. Он также сообщил об одной уязвимости импортируемого пакета
  и семи уязвимостях модулей стандартной библиотеки, которые текущий код не
  вызывает; все указанные исправления входят в Go 1.26.6.

Перед квалификацией релиза проверка повторяется на Go не ниже 1.26.6. Нулевой
результат по достижимым символам не заменяет проверку образов через утверждённый
security MCP после появления релизных артефактов.
