# Engineering Governance Discovery

Before modifying this repository:

1. Read the root `AGENTS.md`.
2. Initialize the pinned `.engineering-public` submodule.
3. Read `.engineering-public/README.md` and every public policy it requires.
4. For internal, release, infrastructure, migration, secret, or production
   work, initialize and read the approved local `.engineering-private` overlay
   before proceeding.

This file is a discovery adapter, not an independent policy source. Public
governance applies before the private overlay and repository-specific rules.
